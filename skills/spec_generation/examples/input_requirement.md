# 仕様書生成スキル: 入出力例

## 入力例

### 要件（自然言語）

```
ユーザーがメールアドレスとパスワードでログインできる機能を追加したい。
- ログイン画面にはメールアドレスとパスワードの入力フィールドがある
- 「パスワードを忘れた方」リンクがある
- ログイン成功時はホーム画面に遷移する
- ログイン失敗時はエラーメッセージを表示する
- 対応要件: FR-C01
```

### パラメータ

```yaml
specType: auto
requirementIds: "FR-C01"
detail: standard
```

---

## 期待される出力

### 出力ファイル 1: `docs/specifications/01_screen_login.md`

```markdown
# 画面仕様: ログイン画面

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| 画面ID | SCR-001 |
| 画面名 | ログイン画面 |
| 対応要件 | FR-C01 |
| ルートパス | /login |
| 認証要否 | 不要 |
| ステータス | Draft |

## 2. 画面概要

### 2.1 目的
未認証ユーザーがメールアドレスとパスワードを入力し、アプリにログインする。

### 2.2 画面遷移

| 遷移元 | トリガー | 遷移先 |
|---|---|---|
| スプラッシュ画面 | 未認証判定 | 本画面 |
| 本画面 | ログイン成功 | ホーム画面（置換遷移） |
| 本画面 | 「パスワードを忘れた方」タップ | パスワードリセット画面 |
| 本画面 | 「新規登録」タップ | 新規登録画面 |

## 4. UI要素詳細

### 4.2 入力フィールド仕様

| フィールド | ラベル | 型 | 必須 | 最大長 | バリデーション | キーボード |
|---|---|---|---|---|---|---|
| email | メールアドレス | email | Yes | 254 | RFC 5322形式 | emailAddress |
| password | パスワード | password | Yes | 128 | 8文字以上 | visiblePassword |

## 5. 状態遷移

| 状態 | 条件 | 表示内容 |
|---|---|---|
| Initial | 画面表示直後 | 空のフォーム |
| Validating | 入力中 | リアルタイムバリデーション結果 |
| Submitting | ログインボタンタップ後 | ボタンにローディング表示、入力無効化 |
| Error | ログイン失敗 | エラーメッセージ（SnackBar）、フォーム再入力可能 |

## 9. エラー表示

| エラー種別 | 表示方法 | メッセージ |
|---|---|---|
| 未入力 | インラインエラー | 「メールアドレスを入力してください」 |
| フォーマット不正 | インラインエラー | 「有効なメールアドレスを入力してください」 |
| 認証失敗 | SnackBar | 「メールアドレスまたはパスワードが正しくありません」 |
| ネットワークエラー | SnackBar | 「通信に失敗しました。再度お試しください」 |
| アカウントロック | ダイアログ | 「アカウントがロックされています。30分後に再度お試しください」 |
```
