## 使い方

1. 本テンプレートをコピーし、`ADR-[連番3桁]_[簡潔なタイトル].md` として保存する
   - 例: `ADR-001_state_management_selection.md`
2. 各セクションを記入する
3. チームレビューを経て、ステータスを `Accepted` に更新する
4. 過去のADRを変更する場合は、新しいADRを作成し `Superseded by ADR-YYY` とする（上書き禁止）
